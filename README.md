# Discovery Workshop: printable teaching tools

By Nimesh / NimeshBuilds.

[Download the printable tools and cards](https://raw.githubusercontent.com/nimeshbuilds/discovery-workshop-resources/main/Discovery-Workshop-Printable-Tools.pdf)

This supplement provides the 15 reusable tool sheets and 31 optional card sheets from **Discovery Workshop: Teaching Guide and Answer Key**. It is designed for the 13-week, 65-day learning curriculum.

## Printing

- Use US Letter paper, single-sided, at **Actual Size / 100%**. Turn off Fit to Page.
- The 46 PDF sheets retain the original teacher-book footer numbers 245–290. PDF sheet 1 is teacher page 245; subtract 244 from a teacher page number to find the PDF sheet.
- Copy only the sheets named in the weekly preparation list. Use the R07 one-inch square on PDF sheet 11 (original page 255) to check scale.
- Adults handle scissors. Store and reuse the pieces. Keep small pieces away from younger children.

The complete teaching instructions and answers are in the teacher book. The child-facing activities are in **Discovery Workshop: Student Activity Book**, sold separately. This supplement contains neither complete book.
